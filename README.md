# Relific Frontend Assessment – Section B

## Overview
This project demonstrates a B2B customer integration dashboard that syncs data from
multiple sources (MongoDB, Frappe, Zoho) using mocked APIs.

## Features
- Mock APIs with simulated latency and failures
- Retry mechanism with exponential backoff
- Partial failure handling
- Sync status & last updated time
- Search, filter, and pagination
- Error Boundary for graceful UI failure
- Built with React + TypeScript + CSS Modules

## Tech Stack
- React (Hooks)
- TypeScript
- CSS Modules

## Notes
External systems are mocked as per assessment scope.
In a production setup, real APIs would replace mock services.
